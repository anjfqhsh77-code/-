# 끝말잇기

브라우저에서 바로 돌아가는 한글 끝말잇기 게임입니다.
`끝말잇기.html` 파일 하나가 전부이고, **더블클릭하면 브라우저에서 열립니다.**
설치도, 인터넷 연결도 필요 없습니다.

## 하는 법

1. `끝말잇기.html`을 더블클릭합니다.
2. 낱말을 입력하고 Enter를 누르면 컴퓨터가 받아칩니다.
3. 먼저 낱말을 못 내는 쪽이 집니다.

한글 입력기 특성상 Enter를 한 번 누르면 글자가 확정되고, 한 번 더 누르면 단어가 제출됩니다.
오른쪽 `내기` 버튼을 눌러도 됩니다.

## 설정

- **난이도** — 쉬움(상대가 이어 가기 쉬운 낱말) / 보통(무작위) / 어려움(상대가 받을 낱말이 가장 적은 쪽으로 몰아감)
- **선공** — 나 또는 컴퓨터 (새 판부터 적용)
- **제한 시간** — 없음 / 10초 / 20초 / 30초
- **힌트** — 한 판에 세 번, 낼 수 있는 낱말을 입력창에 넣어 줍니다

## 규칙

- 두 글자 이상의 한글 낱말만 쓸 수 있습니다.
- 앞말의 끝 글자로 시작해야 합니다.
- 두음법칙을 인정합니다. 예를 들어 `보리` 다음에는 `리본`도 `이불`도 됩니다.
  - ㄹ + ㅑㅕㅛㅠㅣ 계열 → ㅇ (례 → 예, 리 → 이)
  - ㄹ + 그 밖의 모음 → ㄴ (락 → 낙, 로 → 노)
  - ㄴ + ㅑㅕㅛㅠㅣ 계열 → ㅇ (녀 → 여, 뇨 → 요)
  - 반대 방향(`여` 다음에 `려`)은 인정하지 않습니다.
- 이미 나온 낱말은 다시 쓸 수 없습니다.
- 사전에 있는 낱말만 인정합니다.

## 단어 사전

낱말 341개가 HTML 파일 안에 들어 있습니다.
늘리려면 파일을 메모장이나 편집기로 열어 `var WORDS =` 로 시작하는 줄 아래의
낱말 목록에 띄어쓰기로 구분해 추가하면 됩니다.

```js
var WORDS = `
    가구 가랑비 가로수 ...
  `.trim().split(/\s+/);
```
