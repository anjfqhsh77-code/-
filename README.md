# 최X용ver1 채팅봇

단톡방 말투를 흉내 내서 대꾸하는 패러디 채팅봇입니다.
`index.html` 파일 하나가 전부이고, **더블클릭하면 브라우저에서 열립니다.**
설치도, 로그인도, 인터넷 연결도 필요 없습니다.

## 링크로 뿌리려면

GitHub Pages를 켜면 누구나 열 수 있는 주소가 생깁니다.

1. 레포 **Settings → Pages**
2. Source를 **Deploy from a branch**로
3. Branch를 이 브랜치, 폴더는 `/ (root)`로 두고 Save
4. 1~2분 뒤 `https://anjfqhsh77-code.github.io/-/` 에서 열립니다

이 주소를 카카오톡에 그대로 붙여넣으면 됩니다. 받는 사람은 계정도 앱도 필요 없습니다.

## 어떻게 대답하나

인공지능이 아니라 **미리 써 둔 대사를 규칙으로 골라 던지는 방식**입니다.

- 대사를 주제별 창고(`POOLS`)에 나눠 담아 뒀습니다 — 부름, 인사, 사과, 칭찬, 시비,
  밥, 일, 돈, 날씨, 자랑, 게임, 질문 등 20여 개
- 상대 말에 어떤 낱말이 들어 있는지 보고(`RULES`) 맞는 창고를 엽니다
- 맞는 게 없으면 상대가 쓴 낱말을 그대로 되받아치거나(`echo`) 아무 말이나 던집니다
- 한 번에 **한 줄, 길어야 두 줄**만 보냅니다
- 같은 말이 연달아 나오지 않게 창고마다 뽑기 주머니를 돌립니다
- 30초쯤 답이 없으면 먼저 찝쩍댑니다 (최대 3번)

그래서 아주 새로운 주제에는 동문서답을 합니다. 그건 한계가 맞습니다.

## 대사 고치기

`index.html`을 편집기로 열어 `var POOLS = {` 아래를 고치면 됩니다.

```js
food: [
  "나 지금 치킨기다리고잇어^^",          // 문자열 하나 = 단답
  ["니는 뭐먹엇어??", "밥은 제때먹고다니냐고"]  // 배열 = 두 줄
],
```

어떤 말에 어떤 창고를 열지는 그 아래 `var RULES = [` 에서 정합니다.

## 알아둘 것

패러디입니다. 실제 인물의 발언이 아니고, 나오는 말은 전부 지어낸 것입니다.
욕설은 원본 기록과 같게 가려서 넣었습니다.

# 끝말잇기

브라우저에서 바로 돌아가는 한글 끝말잇기 게임입니다.
`끝말잇기.html` 파일 하나가 전부이고, **더블클릭하면 브라우저에서 열립니다.**
설치도, 인터넷 연결도 필요 없습니다.

## 하는 법

1. `끝말잇기.html`을 더블클릭합니다.
2. 낱말을 입력하고 Enter를 누르면 컴퓨터가 받아칩니다.
3. 먼저 낱말을 못 내는 쪽이 집니다.

한글 입력기 특성상 Enter를 한 번 누르면 글자가 확정되고, 한 번 더 누르면 단어가 제출됩니다.
오른쪽 `내기` 버튼을 눌러도 됩니다.

## 설정

- **난이도** — 쉬움(상대가 이어 가기 쉬운 낱말) / 보통(무작위) / 어려움(상대가 받을 낱말이 가장 적은 쪽으로 몰아감)
- **선공** — 나 또는 컴퓨터 (새 판부터 적용)
- **제한 시간** — 없음 / 10초 / 20초 / 30초
- **힌트** — 한 판에 세 번, 낼 수 있는 낱말을 입력창에 넣어 줍니다

## 규칙

- 두 글자 이상의 한글 낱말만 쓸 수 있습니다.
- 앞말의 끝 글자로 시작해야 합니다.
- 두음법칙을 인정합니다. 예를 들어 `보리` 다음에는 `리본`도 `이불`도 됩니다.
  - ㄹ + ㅑㅕㅛㅠㅣ 계열 → ㅇ (례 → 예, 리 → 이)
  - ㄹ + 그 밖의 모음 → ㄴ (락 → 낙, 로 → 노)
  - ㄴ + ㅑㅕㅛㅠㅣ 계열 → ㅇ (녀 → 여, 뇨 → 요)
  - 반대 방향(`여` 다음에 `려`)은 인정하지 않습니다.
- 이미 나온 낱말은 다시 쓸 수 없습니다.
- 사전에 있는 낱말만 인정합니다.

## 단어 사전

낱말 341개가 HTML 파일 안에 들어 있습니다.
늘리려면 파일을 메모장이나 편집기로 열어 `var WORDS =` 로 시작하는 줄 아래의
낱말 목록에 띄어쓰기로 구분해 추가하면 됩니다.

```js
var WORDS = `
    가구 가랑비 가로수 ...
  `.trim().split(/\s+/);
```
